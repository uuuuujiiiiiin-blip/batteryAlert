# 🔋 방전알리미 (Battery Alert)

**팀 RE:VOLT**

**주차하기 전에 내일 아침 시동이 걸릴지 미리 알려주고, 12V 배터리가 위험하면 스스로 지켜주는 Pleos Connect 차량 앱**

차량 신호(공조·열선·전조등·좌석·기어)와 날씨 예보로 12V 배터리 잔량을 실시간으로 추정하고, 시동이 어려워지기 전에 원인과 해결 방법을 알려줍니다.

---

## 주요 기능

| 구분 | 기능 |
|---|---|
| 예측 | 주차 시 시동 가능 시간 예측, 시간대별 기온을 반영한 시동 한계 그래프, 추정 신뢰도 표시, 퇴근길 도착 전 경고와 충전 경로 |
| 보호 | 12V 보호 하한선(P단 자동 OFF, 1분 전 예고·유지 선택), 차박·대기 모드 남은 시간 + what-if |
| 기록 | 주차 에너지 영수증, 주간 리포트(절약 제안), 장소별 주차 프로필, 12V 관리 점수 |
| 안내 | 겨울 출발 브리핑, 방전 대처 가이드(3단계 + 긴급출동 전화), 정비소 공유 QR |
| 음성 | Pleos 음성 인식·안내로 질문과 차량 제어 ("내일 아침 시동 괜찮아?", "열선 다 꺼줘") |
| 절전 | 하차 2분 뒤 차량 읽기·네트워크 요청을 모두 멈춤 (앱이 주차 중 차를 깨우지 않음) |

> 안전 원칙: 앱은 **전조등을 절대 끄지 않고**, 차량 제어는 **P단에서만** 합니다. 주행 중에는 열선만 줄이도록 안내합니다.

## 실행에 필요한 설정

### 1. Virtual Console 연결
에뮬레이터를 켤 때마다(재부팅 포함) 한 번 실행해 주세요.

```
adb forward tcp:8088 tcp:8088
```

### 2. 에뮬레이터 시간대 (재부팅 시 초기화되므로 매번 실행)
출발 시각·날씨 계산이 한국 시간 기준이라서 필요합니다.

```
adb shell settings put global auto_time_zone 0
adb shell cmd alarm set-timezone Asia/Seoul
```

### 3. 권한
차량 권한(CAR_CLIMATE, CAR_SEATS, CAR_SAFETY 등)과 음성 권한은 매니페스트에 선언되어 있습니다. 처음 음성 버튼을 누를 때 마이크 권한을 허용해 주세요.

### 4. 카카오 REST API 키 (소스에서 빌드할 때만)
보안을 위해 키는 저장소에 올리지 않았습니다. 소스에서 직접 빌드하는 경우, 프로젝트 최상위의 `local.properties`에 아래 한 줄을 추가해 주세요. 제공된 APK에는 이미 포함되어 있습니다.

```
KAKAO_REST_KEY=발급받은_REST_API_키
```

> `adb` 명령을 찾을 수 없다고 나오면 Android SDK 경로의 adb를 직접 실행해 주세요.
> 예: `"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" forward tcp:8088 tcp:8088`

## 앱 실행 방법

### APK로 바로 실행
1. 저장소의 `apk/REVOLT_Battery_Alert_release.apk`를 내려받습니다.
2. Pleos Connect 에뮬레이터를 켠 상태에서, APK가 있는 폴더에서 설치합니다.
   ```
   adb install REVOLT_Battery_Alert_release.apk
   ```
   > 폴더 경로에 한글이 들어 있으면 설치가 실패할 수 있습니다. 영문 경로(예: `C:\apk`)에 두고 설치해 주세요.
3. 위의 "실행에 필요한 설정" 1·2번을 실행한 뒤 앱을 엽니다.

### 소스에서 빌드
1. 저장소를 내려받아 Android Studio로 엽니다.
2. `local.properties`에 카카오 키를 추가합니다.
3. Gradle Sync 후 Pleos Connect 에뮬레이터를 선택하고 실행(▶)합니다.

## 기능 확인 방법 (시연 플로우 10단계)

핵심 기능 10가지를 차례대로 확인하는 순서입니다. 각 단계는 **준비 → 조작 → 확인할 결과** 순서로 적었습니다.

### 0. 공통 준비 (처음 한 번)
1. 위의 "실행에 필요한 설정" 1·2번을 실행하고 앱을 엽니다.
2. 상단 **🧪 시연 패널**을 엽니다.
3. 겨울 상황을 만들기 위해 시연 패널에서 **[외부 API] 날씨 자동**을 끄고, **[수동] 외기온도**를 **−12°C**로 맞춥니다.
4. 상단 **⚙ 설정**에서 **자동 보호**가 켜져 있는지, **주차녹화(상시녹화) 사용**이 켜져 있는지 확인합니다.
5. 이전 기록을 지우고 싶으면 시연 패널의 [주차 기록 지우기], [점수 기록 지우기], [위험 기록 초기화]를 누릅니다.

> 같은 주차에서는 하차 팝업이 1번만 뜹니다. 다시 보려면 Console에서 기어를 **D → P**로 바꿔 새 주차를 만들어 주세요.

---

### ① 주차 시 시동 예측 · 하차 팝업
- **준비:** Console에서 기어 **D** → 시트 열선 ON, 공조 팬 ON
- **조작:** Console에서 기어 **P** → 운전석 문 열기 (또는 P 상태로 10초 유지)
- **확인할 결과**
  - "⚠ 내리기 전에 확인하세요" 팝업과 음성 안내가 나옵니다. 꺼야 할 항목이 효과가 큰 순서대로 표시됩니다.
  - **[공조·열선·창문 끄기]**를 누르면 Console에서 열선·공조가 꺼진 것을 확인할 수 있습니다. 전조등은 안전상 끄지 않고 안내만 합니다.
  - **홈 탭** 판정 카드(초록/노랑/빨강)와 **시동 한계 그래프**를 확인합니다. 파란선 = 추위 반영 12V, 빨간 점선 = 시동 한계, 초록선 = 블랙박스를 끄면 늘어나는 여유입니다.

### ② 퇴근길 도착 전 경고 · 충전 경로
- **준비**
  - ⚙ 설정 → **정비소 측정값으로 보정** 슬라이더를 **45%**로 맞추고 **[이 값으로 보정]**을 누릅니다.
  - 시연 패널 → **집으로 주행 중** ON, 도착까지 **15분** 정도로 맞춥니다.
  - (선택) 주행 중에도 전체 화면을 보려면 P 상태에서 **주행 중 화면 제한 풀기**를 미리 켭니다.
- **조작:** Console에서 기어 **D**. 3초마다 도착 시간이 1분씩 줄어듭니다.
- **확인할 결과**
  - 도착 10분 이하가 되면 "🏠 집 도착 약 N분 전 — 내일 아침 시동 위험/주의" 배너와 음성이 나옵니다. 주행 중이라 팝업 대신 배너로 안내합니다.
  - 배너에 "열선 끄고 약 N분 더 달리면 회복 가능 (필요 %, 부족 %p)"가 표시되고, **[N분 더 걸리는 경로로 회복]** 버튼으로 충전 경로를 안내합니다.

### ③ 12V 보호 하한선 자동 OFF
- **준비:** Console에서 기어 **P** → 시트 열선 ON, 공조 팬 3단 이상
  - 부하가 충전 여유보다 작으면 "지금은 12V가 충전 중이라…" 안내가 뜹니다. 이때는 핸들 열선·미러 열선·전조등을 추가로 켜서 부하를 늘려 주세요.
- **조작:** 시연 패널 **[시연용] Y1 보호 하한선**에서 버튼을 순서대로 누릅니다.
  1. **[29분 전]** → 홈 맨 위에 보호 하한선 배너가 표시됩니다.
  2. **[9분 전]** → "약 N분 뒤 12볼트가 보호 하한선에 닿아요" 음성이 나옵니다.
  3. **[2분 전]** 또는 **[도달]** → "1분 뒤 공조와 열선을 자동으로 꺼요" 예고와 60초 카운트다운이 시작됩니다.
- **확인할 결과**
  - 카운트다운이 끝나면 Console에서 공조·열선이 **자동으로 꺼지고**, 배너가 초록색 완료 상태로 바뀝니다.
  - 카운트다운 중 **[유지]**를 누르면 이번 주차 동안은 자동으로 끄지 않습니다. 다시 시험하려면 기어를 **D → P**로 바꿔 주세요.

### ④ 차박·대기 모드 + what-if
- **준비:** Console에서 기어 **P**, 운전석 착석 ON, 열선·공조 ON
- **조작:** 시연 패널 **[대기 모드 제안 바로 띄우기]** → 홈 맨 위 제안 카드에서 **[대기 모드로 보기]**
  - 실제로는 P·착석·공조/열선 상태가 5분 이어지면 자동으로 제안합니다. 상단 **🛏 대기 모드** 버튼으로 바로 켤 수도 있습니다.
- **확인할 결과**
  - "🛏 차박·대기 모드" 카드에 **남은 시간**, 보호 하한선 그래프, 항목별 전기 사용량이 표시됩니다.
  - what-if 목록에서 항목별 **[끄기]**를 누르면 그 장치가 꺼지고 남은 시간이 늘어납니다.
  - 하한선에 닿으면 1분 전에 예고하고 **열선부터** 끄고, 그래도 부족하면 공조까지 끕니다.
  - 내연기관 계산을 보려면 시연 패널 **내연기관으로 계산**을 켜고, 카드의 **시동 끄고 대기 중** 토글을 바꿔 봅니다. 전기차는 고전압 배터리 기준 시간도 함께 계산합니다.

### ⑤ 음성 질문 · 차량 제어
- **조작:** 홈 탭 음성 카드의 마이크 버튼을 누르고 말합니다. 에뮬레이터 마이크가 불편하면 시연 패널 **[시연용] X6 음성 명령** 버튼으로 같은 문장을 글자로 보낼 수 있습니다.
- **확인할 결과**

| 말하기 | 결과 |
|---|---|
| "내일 아침 시동 괜찮아?" | 지금 12V 잔량, 판정, 하한선까지 남은 시간을 음성으로 답변 |
| "열선 다 꺼줘" | P단에서 열선을 끄고 결과를 음성으로 안내 |
| "왜 위험해?" / "어떻게 해?" | 위험 원인과 효과 큰 조치 순서 안내 |
| "창문 닫아줘" | 창문 닫기 |
| "내일 8시에 출발해" | 출발 시각을 바꾸고 판정을 다시 계산 |
| "블랙박스 껐어" / "블랙박스 전압 12.3볼트" | 블랙박스 상태 반영 / 전압으로 12V 보정 |
| "대기모드" / "영수증" / "뭐 할 수 있어?" | 대기 모드 시작 / 영수증 화면 열기 / 도움말 |

### ⑥ 주차 에너지 영수증 · 주간 리포트
- **준비:** ⚙ 설정에서 주차녹화 ON (블랙박스 비중이 영수증에 표시됩니다)
- **조작**
  1. 시연 패널 **[어젯밤 14시간 주차]** → 홈 탭 맨 위에 **🧾 주차 에너지 영수증**이 나옵니다.
  2. 영수증의 **[주간 리포트]** 또는 시연 패널 **[최근 7일 기록 채우기]**를 누릅니다.
- **확인할 결과**
  - 영수증에서 주차 중 어디에 전기가 쓰였는지(블랙박스·대기 전력 등)를 Ah와 비율로 보여줍니다.
  - 주간 리포트에서 일주일 동안 쓴 양과 절약 제안을 보여줍니다. 상단 **🧾 영수증** 버튼으로도 열 수 있습니다.

### ⑦ 장소별 주차 프로필
- **준비:** 날씨 자동 OFF, 외기 −12°C (0단계와 같음)
- **조작:** 시연 패널 **[① 집·회사 프로필 만들기]** → **[② 집(지하)에 주차]**와 **[③ 회사(지상)에 주차]**를 번갈아 누릅니다.
- **확인할 결과**
  - 홈 탭 **📍 지금 장소** 카드에서 같은 12V여도 장소에 따라 위험도가 달라지는 것을 확인합니다. 집(지하)은 실내 보정 온도와 평균 13시간 주차, 회사(지상)는 바깥 기온 그대로와 평균 9시간 주차로 계산합니다.
  - ⚙ 설정 → **장소 프로필**에서 장소 이름과 지하·실내 여부를 바꿀 수 있습니다. 장소 좌표는 기기 안에만 저장합니다.

### ⑧ 겨울 출발 브리핑
- **준비:** 날씨 자동 OFF, 외기온도 **5°C 이하**
  - (선택) 시연 패널 **[시연] 타이어 공기압 부족 신호**, **[시연] 워셔액 부족 신호**를 켜면 겨울 점검 항목에 함께 표시됩니다.
- **조작:** 시연 패널 **[주차 8시간 후 시동]**
- **확인할 결과**
  - "❄ 출발 브리핑" 카드가 10초 동안 표시됩니다. 밤사이 줄어든 12V, 오늘 판정, 겨울 점검 결과가 나오고 **[영수증 보기]**로 이어집니다.
  - **[주차 5시간 (안 뜨는지 확인)]**을 누르면 조건(6시간 이상 주차, 5°C 이하)이 맞지 않아 브리핑이 뜨지 않는 것도 확인할 수 있습니다.

### ⑨ 방전 대처 가이드 · 블루핸즈 · 긴급출동
- **조작:** 시연 패널 **[시연용] Z3 방전 대처 가이드**에서 **[하이브리드]**, **[전기차]**, **[미등록]** 중 하나를 누릅니다.
  - 에뮬레이터는 차대번호(VIN)가 비어 있어서 가짜 VIN으로 시연합니다. 시연이 끝나면 **[가짜 VIN 해제]**를 누릅니다.
  - ⚙ 설정의 **[🔧 방전 대처 가이드]**로도 열 수 있습니다.
- **확인할 결과**
  - 방전됐을 때 할 일이 3단계로 표시됩니다. 동력원(하이브리드·전기차·내연기관)에 따라 안내가 바뀝니다.
  - **[📞 전화 걸기]**로 긴급출동 번호 전화 화면을 열고, **[가까운 블루핸즈]**로 가까운 정비소를 검색합니다. 블루핸즈 검색은 인터넷 연결과 카카오 키가 필요합니다.

### ⑩ 12V 관리 점수 · 정비소 공유 QR
- **조작:** 시연 패널 **[가짜 1주 데이터 (T10)]** → 자동으로 **배터리 건강** 탭으로 이동합니다.
- **확인할 결과**
  - **🏅 이번 주 12V 관리 점수** 카드에서 점수, 등급, 지난주 대비 변화, 주간 추이를 확인합니다. 점수는 100점 만점으로, 주간 최저 여유(40점) · 회복 주행 달성(25점) · 블랙박스 설정(15점) · 경고 후 30분 안에 조치한 비율(20점)을 합해서 계산합니다.
  - **[📱 정비소에 기록 보여주기]** → 최근 기록 요약 QR이 표시됩니다. QR에는 위치·주행 경로를 넣지 않고, 차대번호는 뒤 6자리를 가립니다.

## 에뮬레이터 제한과 시연 신호

- 차량 상태(기어, 좌석, 열선, 공조, 전조등, 문)는 **Virtual Console(localhost:8088)**에서 바꿉니다.
- 에뮬레이터가 지원하지 않는 값은 시연 신호로 대체했습니다.
  - 타이어 공기압·워셔액 경고: 에뮬레이터 미지원 (`not supported`) → 시연 패널의 시연 신호 사용
  - 차대번호(VIN): 에뮬레이터에서 빈 값 → 시연 패널의 가짜 VIN 사용
  - 실제 차량에서는 SDK 값을 그대로 사용합니다.
- 12시간 주차, 7일 기록처럼 실제로 기다려야 하는 상황은 시연 패널 버튼으로 시간을 건너뛰어 재현합니다.

## 개인정보

- 차대번호와 주차 위치 좌표는 기기 안에만 저장하며 외부로 보내지 않습니다.
- 정비소 공유 QR에는 위치·주행 경로를 넣지 않고, 차대번호는 뒤 6자리를 가립니다.
